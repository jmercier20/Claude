# Arduino UNO R4 Learning

A personal learning project for exploring the Arduino UNO R4 (Minima and WiFi variants).

## Project Structure

```
arduino-uno-r4-learning/
├── sketches/       # Arduino .ino sketches and experiments
├── notes/          # Learning notes and documentation
└── resources/      # Reference materials, datasheets, links
```

## Hardware

- **Arduino UNO R4 Minima** – Standard version with Renesas RA4M1 MCU
- **Arduino UNO R4 WiFi** – Adds ESP32-S3 for Wi-Fi/Bluetooth + LED matrix

## Topics to Explore

- [ ] GPIO basics (digital I/O, PWM)
- [ ] Analog input/output
- [ ] UART / I2C / SPI communication
- [ ] Timers and interrupts
- [ ] DAC (12-bit, unique to R4)
- [ ] CAN bus (Minima)
- [ ] Wi-Fi & Bluetooth (WiFi variant)
- [ ] 12x8 LED matrix (WiFi variant)
- [ ] USB HID (keyboard/mouse emulation)
- [ ] HID / USB Serial
- [ ] Op-amp (built-in, Minima)
