Sub Tenants
View and manage every sub-tenant (client) on the platform. Add, edit, suspend, or remove tenant accounts from here.

Tenant Groups
Organize tenants into logical groups. Apply bulk settings and policies to a whole group at once.

Plans & Add-ons
Define subscription plans (Basic, Professional, Enterprise) and optional add-ons. Control feature limits, storage caps, and pricing per plan.

Onboarding
Guided workflows to set up new tenants — provision databases, configure defaults, and run welcome sequences automatically.

Offboarding
Safely decommission departing tenants — export data, revoke access, archive records, and ensure billing is finalized.
Monitoring
❤️ System Health
System Health
Deep-dive health metrics per tenant and globally. Drill into slow queries, failed jobs, and connection issues in real time.
📊 Usage & Analytics
Usage & Analytics
Charts and reports on orders, users, API calls, and storage trends — per tenant or platform-wide, over custom date ranges.
🔄 Database Sync
Database Sync
Monitors replication of totals from each sub-tenant DB into the central database. Shows sync lag, failures, and last-sync timestamps.
⚙️ Jobs & Automations
Jobs & Automations
Schedule and monitor background jobs — invoice generation, health checks, backups. See run history and failure logs.
📝 Audit Logs
Audit Logs
Immutable record of every admin action (who did what, when). Essential for compliance and debugging.

💳 Billing Overview
Billing Overview
High-level financial health — total MRR, outstanding balances, upcoming renewals, and payment failure rates.

Invoices
View, download, and resend invoices for any tenant. Auto-generated invoices land here after each billing cycle.
Administration
👤 Users & Roles
Users & Roles
Manage admin users and permission levels. Assign roles (Super Admin, Support, Read-Only).

Integrations

Settings
Global platform configuration — tutorial mode, widget visibility, branding, and notification preferences.
