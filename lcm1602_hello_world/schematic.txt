LCM1602 (I2C) + LED + Button — Arduino Mega 2560 Wiring Schematic
==================================================================

  Arduino Mega 2560          LCM1602 I2C backpack
  ─────────────────          ────────────────────
  5V          ──────────────  VCC
  GND         ──────────────  GND
  Pin 20 (SDA)──────────────  SDA
  Pin 21 (SCL)──────────────  SCL

------------------------------------------------------------------

  LED (Pin 8)

  Pin 8 ──── 220Ω ──── LED (+) ──── LED (-) ──── GND
                        Anode        Cathode
                      (longer leg) (shorter leg)

------------------------------------------------------------------

  Push Button (Pin 7)

  Pin 7 ──────────────┤ Button ├──────────────── GND

  (No external resistor needed — INPUT_PULLUP is used in code)

==================================================================
Behavior:
  Button NOT pressed → LED OFF, LCD blank
  Button PRESSED     → LED ON,  LCD shows "Hello World"

Component list:
  - Arduino Mega 2560
  - LCM1602 16x2 LCD with I2C backpack
  - 1x LED (any color)
  - 1x 220Ω resistor  (for LED)
  - 1x push button / tactile switch
  - Jumper wires
