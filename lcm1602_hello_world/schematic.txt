LCM1602 (with I2C module) to Arduino Mega 2560 — Wiring Schematic
==================================================================

  Arduino Mega 2560          I2C Module (PCF8574)
  ─────────────────          on the back of LCM1602
                             Pin  Name
  5V  ──────────────────────  VCC
  GND ──────────────────────  GND
  Pin 20 (SDA) ─────────────  SDA
  Pin 21 (SCL) ─────────────  SCL

  That's it — only 4 wires!

==================================================================

  Physical layout on the Mega 2560:

  [ Arduino Mega 2560 ]
   ___________________________
  |                           |
  |  [20 SDA] ───────────────────────┐
  |  [21 SCL] ────────────────────┐  │
  |  [5V    ] ─────────────────┐  │  │
  |  [GND   ] ──────────────┐  │  │  │
  |_________________________|__|__|__|_|
                             │  │  │  │
                             │  │  │  │
  [ LCM1602 I2C backpack  ]  │  │  │  │
   ________________________  │  │  │  │
  | GND  VCC  SDA  SCL    |  │  │  │  │
  |  │    │    │    │     |  │  │  │  │
  |  └────┘    └────┘     |──┘  └──┘  │
  |_______________________|      └────┘

==================================================================
Notes:
  - SDA = Pin 20 on Mega 2560
  - SCL = Pin 21 on Mega 2560
  - Default I2C address is 0x27
    If the display stays blank, change to 0x3F in the code
  - The I2C backpack has a small potentiometer for contrast —
    adjust it with a screwdriver if text is not visible
  - No extra resistors or potentiometers needed

Component list:
  - Arduino Mega 2560
  - LCM1602 16x2 LCD with I2C backpack (PCF8574)
  - 4x jumper wires
